# Pegasbur's Unraid Community Apps

Unraid Community Apps templates for applications maintained by [Pegasbur](https://github.com/pegasbur).

## Applications

### Subtitle Edit

Native Linux Subtitle Edit packaged for Unraid with a browser-accessible desktop interface.

- [Project](https://github.com/pegasbur/subtitleedit)
- [Support](https://github.com/pegasbur/subtitleedit/issues)
- Image: `ghcr.io/pegasbur/subtitleedit:latest`

### BDInfo

Browser-based Blu-ray structure and bitrate analysis powered by `autobrr/go-bdinfo`.

- [Project](https://github.com/pegasbur/bdinfo)
- [Support](https://github.com/pegasbur/bdinfo/issues)
- Image: `ghcr.io/pegasbur/bdinfo:latest`

## Unraid templates

The Community Apps templates are maintained under [`templates/`](templates/).

Application source code, documentation, releases, and container images remain in their respective project repositories.
